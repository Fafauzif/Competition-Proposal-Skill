# Verification checklist

Apply only the checks the requested output needs.

| Area | How to check the actual result |
|---|---|
| Scope and argument | Compare deliverables and their depth to the request item by item. Read the core with appendices closed. Recover the decision, actor, causal chain, outcome, and delivery path. Follow the judging rubric through the document. |
| Competition fit | BCC ties evidence and recommendation to the client's decision. BPC makes the payer, conversion, delivery capacity, cash, and funding logic intelligible. An innovation essay establishes the specific gap in the introduction and makes its intended system understandable in one opening paragraph of Gagasan. Check each flow against the specific rules. |
| Writing | Read running paragraphs, including the first line of each feature. Explain why features matter to the reader's decision; vary pacing. Check that headings help navigation or, for BCC where appropriate, state findings. Check for canned conclusions, forced contrast, generic AI filler, assistant commentary, decorative furniture, and internal source labels. |
| Evidence and numbers | Inspect the actual primary record for consequential claims. If access is insufficient, mark the claim unverified or use supported wording. Reconstruct decisive calculations, signs, periods, conversions, denominators and scenarios. Check the same figure across text, chart, workbook and appendix. Distinguish projections, targets, observed evidence and schematic examples. |
| Figures and layouts | Render the final deliverable, then inspect every page or slide at readable size. Check horizontal-first main exhibits, labels, captions, margins and page breaks. Look for awkward gaps caused by unnecessary breaks or figure settings. Fit or divide an exhibit before shrinking required type. |
| Navigation and files | Verify each sentence's appendix link reaches its exact subsection or figure and the return opens the intended passage. Check actual PDF and DOCX exports separately if both are requested. Verify official page-count rules, links, totals, page numbering, formats, and remove private comments, placeholder text and paths. |
| Deliverable-specific checks | XLSX uses no frozen panes unless the user overrides, with consistent units, functioning formulas and clear inputs/totals. CSV retains clean data rows and columns. PPTX is explicit opt-in and editable where required, with source-supported numbers and working links. |
| Review truthfulness | Count only actual review passes. Record which final version a critic saw. Recheck post-critique edits. Ratings and claims of verification must reflect the actual work and evidence. |

Give a critic a narrow assignment where appropriate: skeptical judge, evidence and numbers, operations, or final-format and reader experience. A representative cold-start test of a reusable skill gives a new reviewer the module and a new brief without proposed answers.
