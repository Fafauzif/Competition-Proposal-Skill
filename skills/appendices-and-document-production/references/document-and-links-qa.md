# Document and links QA

## Claim-level navigation

Use the text structure of the submission and an exhibit register. For each supporting item, record a stable ID, reader question, body sentence, source or derivation, title, location, and return destination. Use the stable ID as a bookmark key. Page numbers can change after reflow.

Example with two links in one paragraph:

> Peta arus mempertahankan lokasi dan tanggal ketika petugas mengganti kedalaman (Gambar A.1). Penampang memperlihatkan posisi sasaran terhadap dasar laut (Gambar B.1).

Link the first parenthetical label to the paired current-map exhibit and the second to the cross-section. Keep each label together when possible. Apply a restrained underline or another visible treatment consistent with the template. A return link can lead to the relevant feature explanation or the appendix index. Where the competition forbids live links, use precise static references that preserve the same mapping.

A basic PDF check can enumerate destinations and confirm pages. Also open or inspect the target position to ensure the viewer jumps to the intended exhibit. Two links that land on the same correct page can still lead to the wrong exhibit. Check hyperlink rectangles over the visible label and any links split by a line break. In DOCX, verify anchors after renaming, reference refresh and export.

## Space and readability

- Give body paragraphs their intended first-line indentation and check how justification handles long technical terms, URLs, citations, and short footnotes. Adjust column widths or apply nonbreaking spaces selectively. Leave short labels and captions left aligned where justification would create gaps.
- Keep the smallest useful visual unit together. Pair cropped screenshots only if the pair remains readable and the original state, values, and provenance remain intact. A tall image can often share a page after a faithful crop or modest reduction. If readability suffers, move it or change the layout.
- Repeat the header on continuation pages of a long table. Use paragraph styles and table settings for controlled breaking. A well-sized continued table can be preferable to a large blank area caused by keeping the whole table together.
- Inspect contents and appendix indexes after final pagination. Read body page transitions and look at the exact start of each appendix. On a final page, let the argument end naturally. Remove empty continuation pages, oversized gaps between headings and exhibits, and decorative headers and rules with no document job.

## Final pass checklist

1. Correct artifact count, filenames, file type, competition page budget, and supplied template.
2. Complete argument in the main submission, exact claim links, distinct purpose for each major exhibit.
3. Captions, cross-references, locator text, references list and source links match the latest artifact.
4. Visible spacing, type, margins, chart labels, data units, no clipping, and no forced or unnecessary gaps.
5. Calculations and formulas reconcile with visible values. Sheets carry no frozen panes when the user's standard applies.
6. Figure types match data, source capture provenance is clear, schematic visuals cannot be confused with empirical results.
7. Affected pages and link targets rechecked after final revisions. Mention any missing final check outside the file.
