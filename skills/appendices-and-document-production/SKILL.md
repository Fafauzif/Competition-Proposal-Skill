# Appendices and Document Production

Read the guidebook, template, and approved scope before formatting. Establish which parts count toward the page limit and what files are due. A useful main submission stands on its own. Keep the assessment, solution mechanism, and most consequential numbers in the argument. Place the calculations, comparisons, diagrams, and supporting observations behind those claims.

## Build a dossier the reader can inspect

1. Choose exhibits by their explanatory or evidentiary job. Prefer charts, diagrams, figures, and useful annotated views; use native tables for exact values, structured comparisons, and lookups. Allow only the text needed for captions, methods, support, or interpretation. Consolidate redundant exhibits and keep the unique evidence the user requested.
2. Give every exhibit a stable identifier and meaningful title. Place a visible hyperlink at the end of each sentence with distinct appendix support. Link to the exact subsection, figure, or table. Several sentences in one paragraph may legitimately link to different targets. In long dossiers, provide an index with links to each exhibit. Give each appendix a relevant return link, with a precise main-text target when available.
3. Prefer wide, shallow graphics in the main proposal when they use the text width and save vertical space. Examples include a landscape process strip and an in-body Gantt. Give appendix figures whichever dimensions best fit their actual labels and relationships. Choose a native table over a cramped graphic when exact lookup is the task. Use the Charts, Figures, and Tables skill for analytical exhibit selection and renderer choice.
4. Let substantive sections share a page when the headings and exhibits fit. Keep a heading with its opening content and a figure with its caption. Use a meaningful crop, proportional resize, or a pair of related exhibits to reclaim space. Keep the final label size readable and retain complete scales, captions, units, and axes. Honor any required section breaks and actual appendix limits.
5. Keep the body easy to read. For Indonesian prose, use first-line indents and justified paragraphs by default. Manage justification and link wrapping so short labels or a final word do not create glaring gaps. Use restrained typography, plain page numbers, and the guidebook's heading hierarchy. Avoid decorative running furniture, badges, repeated banners, checkerboards, automatic stripe fills, and heavy borders.

## Produce the required files

Use the available ChatGPT Work artifact tools or local libraries. A supplied template controls layout where required. Adapt chart or conversion tooling to the available environment while preserving values, labels, geometry, editability where required, and the intended layout.

| Output | Production rules |
|---|---|
| DOCX | Use real paragraph and heading styles, internal bookmarks, actual linked references, native tables where possible, aligned numeric data, and readable continuations. Keep long prose justified where appropriate. |
| PDF | Render the submission and inspect each page. Check hyperlinks after export, including return links, caption adjacency, clip bounds, figure detail, fonts, and PDF bookmarks or destinations. |
| XLSX | Keep all rows and columns unfrozen. Give inputs, headings, and totals purposeful formatting. Use readable widths and heights, consistent units and number formats, and functional formulas where they belong. Recalculate or independently verify critical results. |
| CSV | Preserve predictable fields, clean records, and consistent encoding. Reserve all rows for the data structure, including the header where applicable. |

Use [document and links QA](references/document-and-links-qa.md) for implementation details and a verification route. Keep internal provenance, draft notes, ratings, and tool commentary outside submitted files. Use meaningful source titles and necessary, accurate assumption and scope notes where readers need them.

## Check the exact delivery candidate

Inspect the rendered deliverable at its intended reading size. Follow links from specific claims to the actual exhibit and back. Reconcile figure labels, page count, table cells, captions and formulas with source data. Reinspect affected pages and destinations after each material revision. Retain source files the user requested and use the project handoff or brief chat note for material gaps.
