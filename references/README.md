## Authority and reuse

Use the user's current instruction for the work to perform and the official guidebook for what qualifies as a submission. Apply the guidebook's page count, required sections, citation system, and permitted media before adopting house defaults. Surface a material conflict. When no requirement settles a choice, use the user-confirmed genre preference. Draw on the selected example for the structure or rhetorical move it actually demonstrates.

Built-in examples are private calibration copies. Their authors retain their rights. The archive can contain participant identities and original document metadata. Keep it in the private project. Copy the argument or layout principle into a new draft using fresh language, project evidence, and new figures. Use a clean source document when producing a submission. Claim deployment, observed performance, approval, or source access only when the current project has evidence for it.

## Using the catalog

The catalog lists 752 software entries across 30 categories. Use its contents, keyword search, and entry-level documentation links to identify a candidate. Check what the evidence label means for the exact operation, then inspect the live environment and run a small safe test where useful. A successful import establishes availability for import. A successful sample export establishes that export on its specified input and version.

| Label | Evidence |
|---|---|
| F | A named operation ran this revision, with its output checked. |
| I | An import or executable check passed this revision. |
| D | Publisher documentation or registry evidence was checked this revision. |
| H3 | A named operation ran in the historical revision. |
| H2 | An import or executable check passed in the historical revision. |
| H1 | Documentation or registry evidence was checked in the historical revision. |
| B | The named operation was blocked in the tested environment this revision. |
| HB | An earlier recorded route was blocked. |

Credit bands describe relative effort for a small deliverable. Check current pricing with the provider before any paid action. Follow the user's approval requirements for charges, external uploads, and account grants. Use local synthetic inputs when testing a candidate and actual document data only through an authorized route.
